# java-lotto-precourse

---

## 기능 목록

---

### 입력
- [O] 사용자로부터 로또 구입 금액을 입력받는다.
  - 구입 금액이 숫자가 아니면 예외를 발생시킨다.
  - 구입 금액이 1000원 단위로 나누어 떨어지지 않으면 예외를 발생시킨다.
- [] 사용자로부터 당첨 번호를 입력 받는다.
  - 당첨 번호는 쉼표(,)를 기준으로 입력받는다.
  - 당첨 번호가 6개의 숫자가 아니면 예외를 발생시킨다.
  - 당첨 번호가 1부터 45 사이의 숫자가 아니면 예외를 발생시킨다.
  - 당첨 번호가 중복된 숫자가 있는 경우 예외를 발생시킨다.
- [] 사용자로부터 보너스 번호를 입력 받는다.
  - 보너스 번호가 한 개가 아니면 예외를 발생시킨다.
  - 보너스 번호가 1부터 45 사이의 숫자가 아니면 예외를 발생시킨다.
  - 보너스 번호가 당첨 번호와 중복되면 예외를 발생시킨다.

### 로또 발행
- [O] 구입 금액을 기준으로 발행할 로또 개수를 계산한다.
- [O] 발행할 로또 개수만큼 로또를 발행한다.
  - [O] 로또 한 장을 발행한다. (1~45 범위의 중복 없는 6개 숫자를 뽑아 발행한다.)

### 당첨 검증
- [] 사용자의 로또 번호와 당첨 번호를 비교한다.
  - 일치 개수와 보너스 번호 여부에 따라 등수를 판별한다.
- [] 총 당첨 금액과 구입 금액을 기반으로 수익률을 계산한다.
  - 수익률은 소수점 둘째 자리에서 반올림한다.

### 출력
- [] 사용자가 구매한 로또 번호를 출력한다.
  - 오름차순으로 정렬하여 출력한다.
- [] 등수별 당첨 통계를 출력한다.

### 예외 처리
- [] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨다.
- [] 예외 상황 시 [ERROR]로 시작하는 에러 메시지를 출력한다.
- [] 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
